# IncLang Compiler

IncLang is a simple compiler and interpreter implemented in C++ to demonstrate core compiler design concepts.

## Features
- Lexical Analysis (Lexer)
- Parsing & AST generation
- Semantic Analysis with symbol table
- Direct AST-based interpretation
- Unit testing with GoogleTest

## Technologies
- C++
- Compiler Design Concepts
- GoogleTest

## Purpose
This project was built to gain hands-on understanding of how programming languages are designed and executed internally.
